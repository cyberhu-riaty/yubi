# 通过 CONFIG 换模型和辨识参数

在 `experiments/reproduce_torque_figures.py` 末尾的 CONFIG 中修改路径即可选用下面这些格式的本地文件。路径可以写成 `Path("/绝对路径/文件")`，也可以相对固定的 ROOT（ur10 目录）拼接。XML 依赖的网格和 include 文件也需要保留，且 XML 内的相对引用必须有效。

| 配置字段 | 文件用途 |
| --- | --- |
| source_dir | 输入 MAT 所在目录，仍使用 trajectory_N_all_combinations.mat 命名和现有 MAT 字段 |
| output_root | 输出根目录，下建 archived_rigid 或 recomputed_rigid |
| identified_model_file | 需要评估的辨识模型完整 MuJoCo XML |
| nominal_model_file | 对照模型完整 MuJoCo XML |
| friction_model_file | 内置公式的 JSON 声明，或自定义公式 Python 文件 |
| friction_params_file | 对应摩擦模型的系数 JSON |
| identified_dynamics_file | 可选 JSON，覆盖辨识模型 XML 中部分动力学参数；None 表示全部使用 XML |
| nominal_dynamics_file | 可选 JSON，覆盖对照模型 XML 中部分动力学参数 |
| measurement_params_file | 可选 JSON，使用新的 Kt 将存档滤波电流换算为真机参考力矩；None 沿用旧参考力矩 |

换 XML 或动力学参数后，需设 `rigid_source="recompute"` 才会重新计算动力学。`archived` 使用已有刚体力矩，适合只更换摩擦模型/参数；它不加载 XML，且拒绝指定动力学覆盖文件，避免配置不生效。两种模式都会重新调用摩擦公式。默认文件复现原公式；新系数会产生新的曲线，不再要求与旧图重合。

## 已有公式，只替换参数

`configs/power_friction.json` 定义 `type="power"`：

`tau = (fc + fv * abs(v)**alpha) * sign(v) + b`

系数文件见 `configs/ur10_identified_friction.json`，fc/fv/b/alpha 各为六个数。

`configs/coulomb_viscous.json` 定义 `type="coulomb_viscous"`：

`tau = fc * sign(v) + fv * v + b`

参数 JSON 需要 fc/fv/b，每项六个数；多余的 alpha 不使用。模型声明中的 joint_names 指定每列对应的关节名称，label 用于图例。速度单位 rad/s，输出关节侧力矩 N·m，系数须与所选公式的 SI 单位一致。

## 换动力学辨识参数

可直接准备包含新质量、质心、惯量、armature 的完整 XML，并替换 identified_model_file；这是最完整的方式。也可以在原 XML 上用 JSON 覆盖部分参数：

```json
{
  "bodies": {
    "upper_arm_link": {
      "mass": 11.3194,
      "ipos": [-0.126, 0.0066, 0.0622],
      "inertia": [0.3, 0.4, 0.5],
      "iquat": [1, 0, 0, 0]
    }
  },
  "joints": {
    "shoulder_pan_joint": {"armature": 0.0628}
  }
}
```

上例是格式示意，inertia 数值不是现有辨识结果。只填写需要覆盖的字段；其他项沿用 XML。mass 为 kg；ipos 为相对 body 坐标系的惯性框架位置（质心），单位 m；inertia 为惯性框架中的三个主惯量（kg·m²），iquat 为该框架朝向的 w/x/y/z 四元数；armature 为关节侧附加惯量。包含交叉项的 fullinertia 可在完整 XML 中提供，不可把交叉项直接塞入这个三元 inertia 字段。

`configs/dynamics_example.json` 是可加载的最小覆盖示例。参数会在内存中施加，再调用 mj_setConst 更新模型常量。外部摩擦方案会在内存中清零对应模型的 damping/frictionloss；对照 XML 摩擦方案保留对照模型的内置项。

`configs/measurement_example.json` 保存六个关节的 torque_constant_Nm_per_A；指定它时用 MAT 的 actual_current_filtered_A 重新换算参考力矩，因此误差指标也随新 Kt 改变。

## 一个只通过 CONFIG 路径切换的例子

```python
identified_model_file=Path("/本地模型/robot_identified.xml"),
nominal_model_file=Path("/本地模型/robot_reference.xml"),
friction_model_file=Path("/本地模型/my_friction.py"),
friction_params_file=Path("/本地参数/friction_new.json"),
identified_dynamics_file=Path("/本地参数/dynamics_new.json"),
nominal_dynamics_file=None,
measurement_params_file=None,
rigid_source="recompute",
```

先将文件按接口约定准备好，再修改路径即可。Excel 表、PDF 参数表和任意格式的 CSV 需要先转换成约定的 JSON 或 XML，不能由路径自动推断公式与字段含义。每次运行将实际 CONFIG 写入输出目录的 run_config.json；其记录配置路径，不是输入文件内容的快照。MAT 的旧变量名为兼容历史分析脚本予以保留，图例使用所选摩擦模型的 label。
