# UR10 参考实验回放对比（界面与验收说明）

> 目标：在机器人按处理后的实机参考轨迹运动时，左侧同时显示参考图同源的六关节
> 实测电流/估算力矩、模型无摩擦预测、模型＋非线性摩擦预测与 UR 目标力矩。
> 这是**离线回放**，不是实时采集，也不是正向控制器的跟踪复现。

## 入口

1. 启动软件。
2. 在顶部实验下拉框选择 **「UR10 参考实验回放对比」**，点「加载」。
3. 界面切到「验证」；参考对比面板出现在通用曲线之上。
4. 点顶部「运行」。3D 机器人按 `trajectory_N_identified_results.mat` 里的
   `q_actual_rad/dq_actual_rad_s` 回放；六张曲线图的播放游标同步移动。
5. 暂停/复位沿用现有全局工具栏。运行中不能切换参考轨迹；先暂停或复位。

参考实验与「UR10 实时轨迹跟踪」是两个独立实验：前者是离线存档回放，后者是
MuJoCo 正向仿真；两者不共用同一组曲线含义。

## 面板功能

- **轨迹选择**：0–9，对应处理后的 10 条实机轨迹；参数持久化到当前项目文件。
- **力矩 / 电流**：力矩单位为 N·m，电流单位为 A；两种视图共用同一时间轴。
- **存档参考 / 当前模型重算**：
  - 存档参考：使用参考 MAT 中的 `identified_*` 数组，目标是与 Python 参考图逐点一致；
  - 当前模型重算：读取同一组 q/dq/ddq，用当前 `ur10_extfric.xml` 重新 `mj_inverse`；
    重算线用虚线区分，轨迹 1/7 会显示接触相关差异。
- **六关节 3×2 网格**：每张图四条线（电流视图三条）：
  实测、模型无摩擦、模型＋非线性摩擦、UR 目标力矩；每张图独立纵轴、共享时间轴和游标。
- **播放游标**：横轴是参考运行段仿真时间（0–约 9.1 s），不是墙钟；暂停时游标不动。
- **悬停**：只读取最近真实采样点的数值，不停止回放、不发送控制命令。
- **导出 CSV**：导出当前轨迹、当前物理量（含存档或重算来源）的逐点数值。

## 数据与计算口径

- 输入是 `ur10/experiments/legacy/outputs/results/trajectory_N_identified_results.mat`
  （与 `Downloads/ur10/ur10_experiment/results` 对应文件逐字节相同）。
- 这些 MAT 已经是原始脚本处理后的结果：10 Hz 四阶 Butterworth 零相位低通、
  0.25 s Savitzky–Golay 求导、首尾 0.5 s 裁剪；**原始 49 列 RTDE 记录不在当前工作区**，
  因此目前只能从处理结果复算，不能从原始记录重新核对滤波/求导/裁剪。
- 参考图中的 `measured` 力矩是**滤波电流乘 Kt 的估算力矩**，不是独立关节力矩传感器；
  `identified model + nonlinear friction` 是逆动力学预测，不等于控制器实际施加了摩擦补偿。
- 独立重算结果（2026-11-18，MuJoCo 3.13.0）：
  - 轨迹 0/2/3/4/5/6/8/9：最大差 < 1e-5 N·m，通过；
  - 轨迹 1：223/1130 个采样点超过 1e-5 N·m，最大 45.8268 N·m（t≈6.512 s，J4）；
  - 轨迹 7：26/1139 个采样点超过 1e-5 N·m，最大 20.5753 N·m（t≈3.216 s，J4）。
  - 差异只出现在接触帧（`forearm`–`wrist₂` 碰撞网格）；关闭接触或改接触参数会破坏其余
    轨迹，不能作为修复。详见 `docs/UR10参考图复现差距分析.md`。
- 存档参考数组在 1/7 上仍然逐点可回放；面板把“存档回放”和“当前模型重算”分开标注，
  不会把 1/7 说成完全复现。

## 3D 回放的边界

参考回放插件在每个物理步之后写入处理后的 `q/dq` 并调用 `mj_forward`，让原生视口显示
参考姿态；它不把回放状态当作正向控制器的输出，也不证明位置伺服跟踪了这些参考轨迹。
暂停/复位仍走现有全局仿真控制。
