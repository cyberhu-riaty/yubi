# 驭臂 · 导师演示手卡（8 分钟）

> 打印一页，台上只看这张。详细讲稿见 [导师演示_8分钟流程.md](导师演示_8分钟流程.md)。

**一句话**：底座是 MuJoCo Studio；我做上面的实验台——装配 / 调参 / 录制 / 辨识，加算法不改外壳。

**三条铁律**：① 先算法后重力 ② Apply ≠ Save；KP 后必重置 ③ 3 分钟修不好切录屏。

## 翻车速查（30 秒内）

| 现象 | 先做什么 | 台上话术 |
|---|---|---|
| 不动 | 看【开始推进物理】→ 看【已勾选】有没有 PD → 看 Apply | “两个开关，我确认一下。” |
| 不兼容 | 换回 UR5e | “预检挡住了，这是设计。” |
| 面板没了 | `F9`；还不行 `Shift+F9` 后重启 | “面板可恢复。” |
| 中文变问号 | 点顶栏 `EN`，英文继续 | “中文是补丁，英文是原生兜底。” |
| 录制没反应 | `Ctrl+2` 勾 Recorder，Apply | “录制本身也是一个算法。” |
| 回放不动 | `Ctrl+2` 把 Recorder 用 `v` 下移到 PD 后，Apply | “顺序=谁最后写力矩。” |
| `Load key` 没反应 | 先点 `home` 再 `Load`；或点 `Reset`；或取消/勾回 Recorder → `应用（临时）` | “我换个方式重跑同一个阶跃。” |
| 辨识不支持 | 换回 UR5e | “参数表按模型查，不假装支持。” |
| 终端 `imgui-error` | 不追、不关终端，继续 | “已知告警，窗口还能用。” |
| 崩溃 | 重启（10 s）；不行切录屏 | “正好看启动速度。” |

**降级**：一级跳当前幕 → 二级放 8 分钟录屏 → 三级只讲 4 张截图 + 3 个数字。
