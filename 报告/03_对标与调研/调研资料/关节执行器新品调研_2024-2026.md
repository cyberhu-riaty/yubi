### A5. HONPINE 鸿磐 — **HPJM mechatronic joint module series (2026 flagship)**
- **Why add**: **2026** flagship mechatronic joint family with an unusual degree of documented integration and *publicly posted* datasheet tables; covers harmonic and planetary variants including a **built-in torque-sensor** model — fills both the "harmonic joint" and "joint torque sensing" slots.
- **Verified facts**:
  - **HPJM architecture** = MEA (Motor + harmonic **Reducer** + embedded low-voltage **servo driver** + dual position encoders & high-speed brake), **large hollow bore** for routing pneumatics + power + signal through the centre, **CSP (cyclic synchronous position) mode** and **feedforward control** explicitly supported. Driver is **fully embedded**. Article dated **2026-06-16**.
  - **TCHL series** harmonic joint module (**announced 2026-01-27**): **integrated force/torque sensor on the reducer side** → closed-loop **force and position** control; **output encoder** measures true joint output angle (bypasses harmonic internal error); fully integrated cables/connectors; **size-14 model weighs only 0.5 kg**; multiple mounting options (double-sided, single-sided, bilateral through, bottom, radial, rod).
  - **HAG series** harmonic gear motor with built-in driver at the base — **and a 2026 revision announced 2026-04-17** that adds an **internal torque sensor (optional) enabling force–position hybrid control** and **a single module can achieve torque closed-loop control**. Integrated: high-torque precision harmonic reducer + frameless torque motor + **torque sensor (optional)** + absolute encoder + **electromagnetic brake (optional)** + driver. **Positioning accuracy ≤10 arcsec, repeat positioning ≤2 arcsec**; precision maintained **>10,000 h**; maintenance-free reducer; fully sealed; hollow shaft for cables / air pipes / **laser beams**. **Brake and torque-sensor variants have essentially the same dimensions** (valuable for packaging). Comms: **EtherCAT + CiA402, CANopen + CiA402**, plus CAN-FD and RS485 Modbus; **CSP / CSV / CST cyclic synchronous modes**; real-time PID adjustment; **variable load-inertia identification** to auto-tune parameters. Encoders: **20-bit high-speed side + 19-bit output side**; 2×24 V digital I/O + **±10 V analog interface**; USB debug interface with live position/speed/current loop access. ⚠️ **CSC/CST is effectively a torque-passthrough path.**
  - **HAT series**: harmonic models 11–58, **rated torque 4 → 1200 N·m**, OD 62–220 mm, **multi-turn absolute encoder with Tamagawa protocol** (single-turn 17-bit/multi-turn 16-bit, or single-turn 23-bit/multi-turn 16-bit), custom dual-encoder configs.
  - **Planetary joint actuator** (EtherCAT/CAN, large hollow, dual encoder) published table: 48 V; ratio 5 → rated 6 N·m @100 rpm, peak 3.6 N·m (>3 s), peak speed 700 rpm; ratio 25 → rated 1.2 N·m @500 rpm, peak 18 N·m, peak speed 140 rpm; torque constant 0.94 / 4.71 N·m/A; 14 pole pairs; **backlash 6 arcmin**; back-drive torque 0.1 / 0.4 N·m; mass **233 / 263 g**; axial load 3.2 kN, radial 1.4 kN; **dual feedback, 14-bit**; IP40; −20…50 °C. *(Note: the ratio-5 vs ratio-25 rated/peak torque values in the published table appear internally inconsistent — quote with care.)*

### A6. 零差云控 ZeroErr — **eRob series harmonic joint modules (eRob70/80/90/110/142/170)**
- **Why add**: the **best-documented industrial-grade** joint for sim-to-real in this whole survey — hollow-shaft harmonic joints with **onboard servo driver, dual absolute encoders, optional built-in torque sensor**, and an **unusually large official open-source software stack** (SOEM/CANopen/ROS2/MoveIt/Python/Isaac).
- **Verified facts** (official user manual **V3.39**, 112 pages, plus vendor GitHub):
  - **Architecture**: servo driver + motor-side absolute encoder + **output-side absolute encoder** + frameless torque motor + brake + precision harmonic reducer, all integrated. Hollow through-bore **18 mm** (20 mm on 142/170). **IP54**. Friction-type brake.

### E2. Structural gaps in the market (answering the framework's core question)
- **A bare *single joint* with driver + open CAN protocol + published MJCF still does not exist as one product.** The closest are: **Hightorque HTDW** (open protocol + SDK + URDF, **no MJCF**), **OpenArm** (MJCF + URDF + SocketCAN + buyable, but it is an *arm*, not a bare joint), and **AgiBot PowerFlow** (perfect docs, **no confirmed sales channel**). Expect to convert URDF→MJCF yourself.
- **However, the *arm-level* version of this now DOES exist** — and it is the most practical answer for a sim-to-real project: **reBot-DevArm** (`seeed_rebot_devarm` MJCF in MuJoCo Menagerie + CERN-OHL-W-2.0 hardware + screw-level BOM + OSHWA-certified, **$1,699** for B601-RS), alongside **OpenArm** (`openarm_mujoco`, $6,500) and the Menagerie entries **`robotstudio_so101`**, **`i2rt_yam`**, **`low_cost_robot_arm`**. Building on one of these gets you a validated joint choice *and* a MuJoCo model on day one.
- **The industrial tier (VEICHI, Leadshine, Laifual, Leaderdrive, HCFA, HONPINE, TC-Drive) is uniformly closed**: zero SDKs, zero ROS 2 drivers, zero URDF/MJCF across all twelve vendors checked. Only VEICHI publishes protocol *content* (CiA402 object dictionary inside a 216-page manual).
- **Price opacity is the norm.** Only **Hightorque** (own store JSON), **Seeed** (Hightorque SKUs), **Unitree** (shop), **Laifual** (third-party reseller) and **OpenArm's manufacturers** publish single-unit prices. Everyone else is quote-only.
