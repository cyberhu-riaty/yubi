# 底部工程面板 C 阶段：3D 变窄时自适应工程面板（右列全宽）

> 用户的要求不是“再加一个固定面板”，而是：**拖右分隔线 → 3D 变窄 → 上下黑边 → 用底部面板吃掉这块空间；3D 始终贴着窗口上边。**
> **面板宽度必须只到 3D/右列，不能延伸到左下角蓝色状态栏；左侧 Web 保持整窗高。**
> 本阶段按这个修正后的理解实现。

## 一、理解与实现

### 触发条件

不是按窗口宽度拍脑袋，而是看 **3D 视口自己的宽高比**：

- 3D 宽度 / 窗口内容高度 ≥ `0.95`：不显示面板，3D 全高，维持现有布局。
- 低于 `0.95`：底部工程面板出现，高度为
  `clamp(190, 50% × 窗口高, 窗口高 − 3D宽 / 0.95)`。
- 3D 变宽回去：面板自动收起。

这样，3D 不会在底部留一条无用的黑边，同时也不会为了“填满”把 3D 挤得太小。

### 布局

```
┌──────────────────────────────────────────────────┐
│ 活动栏 │ Web 工作区（整窗高） │ 3D 视口（贴上边）  │
│        │ 项目/模型/…          │                   │
│        │                      ├───────────────────┤
│        │                      │ 工程面板（右列宽）│
│        │                      │ 日志镜像/筛选/清空│
│        │ 左下角蓝色状态栏      │                   │
└──────────────────────────────────────────────────┘
```

- 面板只占 **3D/右列宽度**，从分隔线右侧开始；**不覆盖左下的蓝色状态栏**。
- 面板可拖动顶部抓手调高/调低，双击抓手收起/展开；高度和收起状态写入 NSUserDefaults，
  重开应用仍保留；最小高 190px，常用记录不被截断。
- 左侧 Web 保持整窗高；面板出现时只让右列分成「3D（上）+ 工程面板（下）」。
- **窄宽加固**（本轮评审的 4/10 修正）：中区只在“侧栏之外还有 ≥620px”时显示；
  不够就隐藏中区、侧栏撑满，避免两列逐字换行。3D 最小宽从 420 提到 560；
  模型名/路径/状态等长字段在固定列宽表里换行，并带 title/复制入口。
- **相机防钻入**：滚轮缩放下限 0.4→1.50，宿主每帧再兜底夹紧；分隔条拖动结束恢复并夹紧；
  拖动后滚轮冷却 2s，避免“拖分隔线/滚轮后机械臂变成巨大局部”的 bug。
- 3D 的 frame 是 `x=Web宽, y=面板高, height=上排高`，所以**顶边永远贴窗口上边**。
- 面板展开时 Web 控制台只被 CSS 隐藏（保持挂载，状态/事件不断），蓝色状态栏仍在左下；
  3D 画布按上排高度重算，不再出现旧画布的上下黑边。
- 3D 工具条仍在窗口顶部；图例移到 3D 底边（上排底部）。

### 日志怎么进原生面板

- Web 端在 `日志.ts` 的 `记()` 里，通过 WKWebView 的
  `window.webkit.messageHandlers.驭臂日志.postMessage` 镜像**真实日志行**。
- 宿主 `LogBridge` 收到后追加到原生 `ConsolePanel`；面板支持：
  - **浅色可读外观**：标题栏浅灰、日志区白底、正文深色等宽 11pt；注意/错误用深琥珀/深红；
    分段控件与清空按钮固定 Aqua 外观，不再“黑底小字看不清”；
  - 全部 / 注意 / 错误筛选；
  - 清空；
  - 最多保留 800 行（显示最近 500 行）；
  - 等宽字体、等级配色。
- **同一份日志，不是第二份**：Web 把当前主日志的**筛选结果、总数、等级筛选**整体推给原生面板；
  原生面板的筛选/清空通过 `驭臂.日志操作` 回到 Web 主日志状态。两边计数、筛选、清空同步，
  面板标题写明“主日志镜像”。
- **原生日志面板保持挂载**：C 面板打开时只由 CSS 隐藏 Web 控制台，不卸载组件；
  否则监听器和筛选状态会消失（本轮真实踩到的 bug）。
- **不是假日志**：面板里的每一行都来自 Web 端真实日志（连接、握手、命令回执、规划/诊断事件）。
- **宽度边界**：面板 `x=Web宽, width=3D宽`，所以左边蓝色状态栏和 Web 工作区完全不受影响；
  分隔线拖动时面板宽度跟着 3D 列变。
- 面板展开时，Web 自己的控制台被隐藏（`data-工程面板="1"` + CSS + React 状态），避免上下两份日志；
  收起后恢复原来的控制台状态。

### 一处必须修的宿主 API

`WKWebView` 没有单参数 `evaluateJavaScript_`；必须调用
`evaluateJavaScript:completionHandler:`。最初事件静默失效，导致 Web 控制台没有收起；
现在改成带 completion handler 的版本，并用 `data-工程面板` 属性让 CSS 立即生效。

## 四、没做的 / 边界

| 项 | 说明 |
|---|---|
| 交互式终端（可输入 shell 命令） | 当前是**真实日志镜像 + 筛选/清空**，不是 PTY。做真终端需要目标（仿真/后端/本机）、回执、权限和沙箱；不做一个无标签 shell。 |
| 手动拖面板高度 | 当前按 3D 宽高比自动计算；用户要的是“自动弹出自适应”，先按自动做。后续可加手柄覆盖/记忆。 |
| 后端 stdout 日志 | 镜像的是 Web 端真实日志；后端进程 stdout 仍只在终端。接它需要额外日志总线，不在本阶段。 |
| 右列面板里的 Web 复杂控件（诊断/命令台） | 原生面板只做日志镜像/筛选；完整 Web 控制台仍在 3D 变宽时使用。 |
