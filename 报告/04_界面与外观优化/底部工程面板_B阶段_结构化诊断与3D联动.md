# 底部工程面板 B 阶段：结构化诊断 + 3D 关节联动

> 接 A 阶段（诊断页签 / 筛选 / 跟随 / 召回条）。B 只做能落地、可验证的部分：
> **结构化字段 → 插件筛选 → 关节定位 → 原生 3D 高亮**。
> 不做“看起来像终端”的假 shell，也不解析自由文本猜关节。

## 一、做了什么

### 1. 结构化日志字段（契约 v10）

`日志行` 新增可选字段：

- `模块`：规划 / 插件 / 部署 / 诊断 / 辨识 / 控制台
- `插件`：只有调用方**真的知道**插件名时才填（如插件页启用/停用）
- `关节`：只有后端**真的报告**了关节号时才填（如规划瓶颈关节）

来源新增 `规划`、`诊断`；控制台来源筛选、复制/导出都会带上这些结构化字段。
**没有 command_id**：当前回执协议没有跨进程命令号，前端不伪造一个“看起来能对上”的 ID；
命令成败仍以回执为准，日志与回执通过同一次 `命令收尾` 关联。

### 2. 结构化事件来自真实数据

- **规划**：订阅 `规划结果` 帧；当状态失败或限位来源是“估算”时，从
  `瓶颈关节`/`限位来源`/`原因` 生成一条 `来源=规划` 的结构化事件。不是解析字符串。
- **诊断**：订阅 `诊断报告` 帧；只有存在失败项/出错时才生成 `来源=诊断` 的事件，
  详细项放 `细节`。12/12 全过时不刷屏。
- **插件**：插件页的启用/停用命令在 `命令收尾` 时带 `{模块:"插件", 插件: 插件名}`；
  因此插件筛选有真实数据，不是从主题名猜。
- 其余命令（部署/诊断/辨识/规划）也带 `模块`，方便后续按模块筛选/导出。

### 3. 控制台筛选与关节入口

- 新增 `插件` 筛选：选项来自日志里真实出现过的 `插件` 字段。
- 日志行显示插件徽标；有 `关节` 的日志显示 `J2` 这样的可点击徽标。
- 点击 `J*` 发 `命令.高亮`（8 秒），日志里同时出现命令回执；3D 立即高亮。
- 规划视图在瓶颈关节存在时也提供“在 3D 中高亮 J*”按钮。

### 4. 原生 3D 高亮链路

```
Web 组件 ── 命令.高亮 ──► Web桥/命令桥 ──► 高亮应用器（仿真注册表）
                                                  │
                                          高亮桥.设高亮(关节, 秒)
                                                  │
宿主主线程每 6 帧读一次 ──► Viewport.高亮关节 ──► 画_装饰
```

- `命令.高亮` 是**视觉诊断命令**：不改变物理、不改变模型、不参与控制。
- 3D 标记：关节锚点橙色球 + 竖直针 + 针顶球 + 三色短线；
  针是为了解决“关节锚点在连杆内部、球被挡住”的实际问题。
- 原生图例会追加 `· 高亮 J2`，所以即使标记被遮挡也知道当前亮的是哪个关节。
- 超时自动清除（后端夹到 0..60 秒；UI 默认 8 秒）。
- 高亮应用器是内置插件，不进入用户算法清单；没有算法也能用。

## 三、验证

- `契约自检`：**33 通过 / 0 失败**（契约 v10）。
- `tsc --noEmit`：0；Vite build 成功；生成物一致。

- 真实链路：
  1. 发送一组极端关节航点触发规划失败/估算限位；
  2. 控制台出现 `注意 规划 规划结果 J2`，正文包含瓶颈关节 J2；
  3. 点击 J2 → 回执 `命令.高亮 已受理`；
  4. 宿主进程日志 `高亮关节 -> 2`；截图出现橙色标记和图例 `高亮 J2`。
- 插件筛选：日志里真实出现 `关节pd控制` 后，筛选下拉自动出现该选项（没有写死名单）。

## 四、没做 / 为什么

| 项 | 原因 |
|---|---|
| `command_id` 跨进程关联 | 当前回执协议没有命令号；加它要改上下行协议和所有命令调用点。现在用同一次 `命令收尾` 关联日志/回执，不伪造 ID。 |
| 对后端所有模块做结构化事件 | 规划/诊断/插件/命令回执已有真实字段；其他桥接层仍只发文本或状态，不能靠字符串解析硬猜模块/关节。 |
| 插件输入输出/模型要求 | 插件目录元数据没有这些字段；兼容性仍以装配报告为准，不猜。 |
| 全宽面板 / 终端 | C 阶段；需要第二个 WebView 或原生控制台，以及目标/回执/开发模式。 |
| 3D 标记的逐关节名称/编号 | 原生 OpenGL 没有文本渲染；图例给出 `高亮 J2`，日志/按钮给出 J 号。中文标签需要额外字体纹理，不做假 3D 文字。 |
