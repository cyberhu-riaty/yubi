# 界面侧栏改造 · 设计规格（方案 A：自动收起侧栏）

> 状态：**待复核**（用户确认后才进入实施计划）
> 目标一句话：把自研面板从"压在 3D 视口上的浮动窗口"改成"两边随手可叫出的抽出式侧栏"，
> 并把 `Appearance` 搬进与 `File / Help` 同一行的菜单栏 —— **默认状态下 3D 视口零遮挡**。

---

## 1. 背景与已验证的硬约束

### 1.1 现状（实测几何，窗口 1200×828）

| 区域 | 几何 | 内容 |
|---|---|---|
| 顶栏 | 高 24 | `File / Simulation / View / Help`（官方），右接我们的 `Panels` |
| 左列 | `0..296`，通高 746 | 官方 `Options`（官方 19 个面板段全在它里面） |
| 中央 | `(296, 22) 678×746` | 3D 视口（官方 `configure_docking_layout()` 每帧返回这个矩形） |
| 右列 | `975..1200`，通高 | 官方 `Inspector`（上）+ `Properties`（下） |
| 悬浮 | `323,233` 765×448 | **我们的【工作台】窗口 —— 正好压在 3D 上，这就是"弹窗挡视线"** |

### 1.2 已经做过的可行性验证（9 组现场实验，结论可复现）

| 结论 | 证据 |
|---|---|
| ✅ **菜单能挂进 `File / Help` 那一行** | 包装 `imgui.EndMainMenuBar`，在里面 `BeginMenu("Appearance")`：条目尺寸/位置从基准 `(3,5)@(196,0)` 变成 **`79×20 @ (202,1)`** —— 落在顶行 |
| ❌ **现有 `Panels` 菜单一直没画出来** | 同一位置做对照：它**一个条目都没提交**（读到的仍是上一帧旧值 `756×18@(328,269)`）。原因：它注册在 `Priority.INTERNAL - 1`，排在官方 `EndMainMenuBar()` 之后，ImGui 直接拒绝 |
| ❌ **我们的窗口停靠不进官方 Dockspace** | 9 种写法全部失败：切在官方前/后、`DockBuilderFinish` 调/不调、ini 写 `DockId`、塞官方**已有**节点（`0x06`/`0x08`）、整套 `RemoveNode→AddNode→切片→Finish` 重建。结果一致：**`DockId` 记得住，但 ImGui 永不启用停靠**（`IsWindowDocked()=False`，窗口一直浮在 `60,60`）；手写 ini 造出的空节点会被剪掉；v8 里我们重建的版面**下一帧就被官方抢回去**（终局树只剩官方自己的 `1/2/3/4`） |
| ✅ 有用的副产品 | 3D 区真值 `(296,22,678,746)`；窗口位置/尺寸可用 `SetNextWindowPos/Size(Always)` 任意钉住（现有 `Display` 小方框就是这么钉的）；`ux.load_settings/save_settings` 接受自定义 ini 路径（可用来做无副作用的界面实验） |

### 1.3 由此确定的路线

- **做**：菜单栏挂载（已验证）+ 抽出式侧栏（纯窗口定位，不碰官方 Dockspace）。
- **不做**：任何"停靠进官方 Options / Inspector"的尝试 —— 已证实此路不通，禁止后人重走。

## 2. 目标与非目标

**目标**
1. 默认状态（未展开、未钉住）下，3D 视口**无任何覆盖**；侧栏只占两侧各 26px。
2. `Appearance` 出现在与 `File / Help` 同一行的菜单栏里，**点开即可直接切换基底主题与 5 套风格**，不必打开任何窗口。
3. 其余面板按用途分列两侧，随手叫出、随手收起，永不"找不回来"。

**非目标**
- 不改官方 19 个面板的布局与行为；不做真停靠；不动算法/仿真侧任何代码。
- 不改各面板**内容**的排版（只换它被画在哪儿）。

## 3. 界面规格

### 3.1 侧栏标签条（收起态）

| 项 | 左条 | 右条 |
|---|---|---|
| 位置 | 贴在 **3D 区内侧左边缘**：`x = 3D.x .. 3D.x+26` | 贴在 **3D 区内侧右边缘**：`x = 3D右-26 .. 3D右` |
| 尺寸 | `26 × 3D高`（纵向与 3D 区对齐） | 同左 |
| 标签 | `Model` `Algo` `Ctrl` `SysID`（4 格） | `Monitor` `Recorder` `About`（3 格） |
| 画法 | 竖排文字（**逐字符换行绘制**，官方字体没有旋转文字接口）；每格高 = 字数×行高 + 内边距，居中排布 | 同左 |
| 交互 | 悬停高亮；点击 = 展开/收起 | 同左 |

> 位置每帧从官方 `configure_docking_layout()` 返回的矩形算，**不写死像素**：官方将来改版面（3D 变宽变窄、工具栏显示与否）我们不用改代码。

### 3.2 抽出式面板（展开态）

- 位置：紧贴标签条外侧。左面板 `x = 标签条右 + 0`，右面板 `x = 标签条左 - 宽`；顶部与 3D 区顶部对齐（+8px 留白）。
- 尺寸：宽 **300**，高 `min(600, 3D高 - 16)`。
- 同时展开的规则：
  - **临时展开**：同一时刻只允许一侧展开一个（另一侧的临时展开自动收起）。
  - **钉住**：可两侧同时钉住（300 + 26 + 26 + 300 = 652 < 678，不重叠）。
- 窗口标志：`NoTitleBar` + 自绘小标题条（面板名 + 📌 图钉 + ✕ 收起），`NoResize / NoMove / NoCollapse / NoScrollbar / NoSavedSettings / NoBringToFrontOnFocus`。
- 内容：调用该面板自己的 `_画内容()`（沿用现有容器约定，**面板文件零改动**）。
- 出错隔离：单个面板 `_画内容()` 抛异常 → 只在该面板里显示 `[fail]`，其余照常（沿用现有做法）。

### 3.3 菜单栏

```
File  Simulation  View  Help  Panels  Appearance
```

- **`Appearance`**（新）：
  - `Base theme` ▸ `Light` / `Dark` / `Classic`（单选，打勾）
  - `Skin` 分组：`风格表.json` 里 5 套风格逐条列出，当前项打勾，点一下即切换（等价现在的 F10 轮换到的那些）
  - 分隔线 → `Open Appearance panel`（开关【外观】面板的独立小窗口，**默认关**；要色卡/实时预览/FPS 时才开）
  - 末尾灰字提示 `F10 cycles skin`
- **`Panels`**（修好，与 Appearance 同一挂载点）：
  - `Reveal all (F9)` / `Hide side rails` / `Reset layout (Shift+F9)`
  - 每个面板一条：`展开` / `钉住` 开关（等价 Ctrl+1..7）

## 4. 交互与状态机

| 事件 | 行为 |
|---|---|
| 点标签 | 该面板展开；再点收起 |
| 鼠标移出展开面板 | **0.8 秒**后自动收起（**钉住**时不收） |
| 点图钉 | 钉住 ⇄ 取消钉住（写入状态文件，重启保留） |
| `Esc` | 收起当前临时展开的面板（钉住的不动） |
| `Ctrl+1..7` | 直接展开第 N 个面板（顺序 = 左条 4 格 + 右条 3 格） |
| `F9` | 全部找回：显示侧栏 + 收起所有临时展开（钉住保留） |
| `Shift+F9` | 重置版面：清钉住状态 + 清 `~/.mujoco.ini` 里我们窗口的痕迹（沿用现有实现） |
| `F10` | 换风格（不变） |

状态文件 `输出/面板.json` 结构升级为：

```json
{ "版本": 2, "标签条可见": true, "钉住": {"模型库": true}, "上次展开": "模型库" }
```

旧键（`容器可见` / `当前页签` / `弹出`）**不再使用**；读到旧文件时按默认值起步，不报错。
**`弹出` 这个概念随旧容器一起取消**：面板只有"收起 / 展开 / 钉住"三态。
**两个例外（保持独立小窗口，不进侧栏）**：
- 【Display】（`独立窗口 = True`，物理总闸）—— 钉在 3D 左上角不动，用户已确认；
- 【外观】（改为 `独立窗口 = True`）—— 由 `Appearance` 菜单里的 `Open Appearance panel` 开关，默认关。

## 5. 代码改动清单

### 5.1 新增

| 文件 | 职责 |
|---|---|
| `软件/面板/侧栏.py` | 侧栏容器本体：两条标签条 + 抽出面板 + 钉住/自动收起 + 状态持久化。**它自己也是"面板"**（`面板类 = 侧栏面板`），沿用现有"面板目录自动加载"约定，不改 `启动.py`。同时提供 `要展开(名)` / `全部展开()` / `收起全部()` 给菜单与快捷键用 |
| `软件/菜单栏.py` | 包装 `imgui.EndMainMenuBar`（幂等，写法照抄 `皮肤桥.安装包装()`），画 `Appearance` 与 `Panels` 两个菜单；`Appearance` 直接调用 `皮肤桥` 的现有接口 |

### 5.2 修改

| 文件 | 改什么 | 为什么 |
|---|---|---|
| `软件/面板/面板注册表.py` | ① `有容器()` 判据 `"面板容器"` → `"侧栏面板"`；② `_容器即将出现()` 预判的文件名 `面板容器.py` → `侧栏.py`；③ `_页签顺序()` → `侧栏顺序()`（左右分组顺序）；④ `容器可见/当前页签/弹出` 三组 API → `标签条可见/钉住/上次展开`；⑤ `_我们的窗口名` 增补展开面板的窗口名 | 容器换人，但这些函数是所有面板共用的契约 |
| `软件/面板/模型库面板.py` | 删掉 `停靠候选` / `_摆放窗口()` / `_确认摆放()` 与那句"官方停靠栏对接不上"的打印；它在侧栏里就是普通一格 | 那是为"停靠进官方栏"写的死代码，结论已定（§1.2） |
| `软件/面板/外观面板.py` | 类属性加 `独立窗口 = True`（由菜单开关它的窗口）；`__init__` 里的 `皮肤桥.安装包装()` 一字不动 | 换肤引擎挂在这个文件上，文件必须保留；但它不再是侧栏一格 |
| `软件/面板/面板注册表.py`（续） | `是弹出()` / `设弹出()` / `画弹出提示()` 三个 API 随"弹出"概念一起删；删前 grep 全仓确认调用点只剩旧容器与模型库面板 | 避免留下"点了没反应"的死接口 |
| `软件/主程序.py` | 启动提示文字：`工作台/页签/菜单 Panels` → `侧栏/菜单 Appearance` | 提示要与界面一致。★ 只动打印文字，**不得碰【算法装配】区段**（`零改动自检.py` 对它算哈希） |
| `软件/README.md`、`使用说明.md` | §"窗口里有什么"那张表 + 快捷键说明 | 文档与实现同步 |
| `优化（软件优化的报告都放这里面来）/验证/面板注册表自检.py` | 跟着新 API 改名 | 它是面板注册表语义的自检脚本，不更新就会红 |
| `优化（软件优化的报告都放这里面来）/验证/验收面板文字.py` | 若引用了页签/容器概念，一并改 | 字体验收线不能丢 |

### 5.3 删除

| 文件 | 说明 |
|---|---|
| `软件/面板/面板容器.py` | 旧【工作台】页签容器，**直接删除**（回退靠 git；基线 tag `v0.5.2-基线`）。删前确认：它的 `画菜单`（那个没画出来的 Panels 菜单）与 `轮询数字键`（Ctrl+1..9）已迁到 `侧栏.py` / `菜单栏.py` |

### 5.4 一次性迁移（首次启动新版时跑，跑完写标记）

1. 清 `~/.mujoco.ini` 里 `[Window][Workbench]` 段与遗留的悬浮停靠节点记录 —— 沿用 `面板注册表._清理ini()`，但**换一个标记文件**（如 `输出/.侧栏已迁移`），让它再跑一次。
2. 旧 `输出/面板.json` 的键不迁移、不报错（见 §4）。
3. 终端打印一行迁移提示（中文，给人看）。

## 7. 风险与回退

| 风险 | 处置 |
|---|---|
| 侧栏与 3D 抢鼠标 | 标签条固定 26px；展开面板只在需要时出现；两者都不设 `NoInputs`，但空白区不拦事件；`NoBringToFrontOnFocus` 保证不抢焦点 |
| 官方改版面（3D 区变宽窄/工具栏开关） | 位置每帧由 `configure_docking_layout()` 返回值实算，不写死 |
| 侧栏自身画不出来 | `F9` + 菜单 `Panels` 双兜底；`--恢复默认界面` 可回到干净状态 |
| 删容器后有人回退代码 | `面板容器.py` 在 git 里（基线 tag `v0.5.2-基线`），回退即恢复 |

## 8. 实施顺序（供下一步拆计划用）

1. `菜单栏.py`（挂载点 + 两个菜单，含修好的 `Panels`）—— 独立可用，先落地可先受益。
2. `侧栏.py`（标签条 + 抽出面板 + 钉住/自动收起 + 状态持久化）。
3. `面板注册表.py` 契约改名 + `模型库面板.py` 死代码清理。
4. 删 `面板容器.py`，改 `主程序.py` 提示文字与两份文档。
5. 一次性迁移 + 跑完 §6 全部验收项。

## 9. 留待实施时定的小细节（不影响本规格成立）

- 标签条的悬停高亮配色（跟着 5 套皮肤走，还是固定色）。
- 展开面板标题条上要不要再放一个"弹出成独立窗口"的老按钮（默认不做）。
- 标签格之间的分隔线画法（26px 宽内的视觉细节）。
