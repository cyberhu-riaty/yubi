# 驭臂

基于 [MuJoCo](https://mujoco.readthedocs.io/) Studio 的机械臂仿真与控制工作台。项目提供多型号机械臂模型、可插拔控制算法、项目配置、中文/英文界面，以及参数辨识、数据录制和 URDF 转 MJCF 工具。

## 功能概览

- 加载 UR5e、UR10e、Panda、iiwa14、xArm7 等机械臂模型
- 通过独立 Python 文件扩展关节 PD、轨迹、数据录制和参数辨识等算法
- 在工作台中切换模型、算法、界面主题和语言
- 录制运行数据，并对模型参数进行辨识
- 将 URDF 转为 MJCF，补充关节动力学和执行器参数

## 现在能做什么（诚实版）

十个页面，每一项都**接在真实数据上**——没有一处假数据。**完整度按规格与实现对照**：

| 能力 | 真实状态 | 还缺什么 |
|---|---|---|
| 3D 显示 | ✅ 原生渲染、自动取景、关节高亮 | 幽灵姿态、录制回放 |
| 参数表 | ✅ 可编辑 + 范围校验 + **事务提交（全成功或全回滚）** | Reset/Revert、改参审计 |
| 资产库 | ✅ 5 台机械臂，点选即加载 | 检索、预览、URDF 导入 |
| 系统监控 | ✅ RTF/步频/内存 + **病态检出**（振荡/发散/超差/饱和） | 更多告警类型 |
| 诊断 | ✅ 14 套断言在界面里真跑 | 全速采集层 |
| 轨迹规划 | ✅ 关节/CSV/笛卡尔(位置)航点 → 校验 → **落盘** → **执行** → 换约束对比 | 姿态约束、圆弧/直线基本元、jerk 整形 |
| 部署 | ✅ 设备抽象 + 模拟后端 + 安全层 + 控制台 | **真实协议后端**（UDP/串口/CAN）、物理急停 |
| 插件目录 | ✅ 本机算法库清单 + 元信息 + 启用 | 远端安装 |
| 状态栏 | ✅ | — |

> 写着"还缺"的，界面上也如实标注，不会画一个看起来能用的假界面。
> 例如部署页第一屏就写着：**当前后端是模拟后端，不是真机。**

## 快速开始

当前运行环境以 macOS 和 Python 3.10 为基线，并锁定 MuJoCo 3.13.0。

**双击使用**：桌面上的 **`小软件.app`** —— 起服务并自动打开浏览器界面。
另一个 **`小软件（原生界面）.app`** 是原来的 ImGui 原生界面（功能不变，留作对照与退路）。

**命令行**：

```bash
git clone https://github.com/cyberhu-riaty/yubi.git
cd yubi
bash 工具/重建环境.sh

# ① Web 界面（无窗宿主：仿真在主线程，界面在浏览器）
.venv/bin/python 软件/主程序Web.py --检查      # 产物/契约/模型/端口逐条自检
.venv/bin/python 软件/主程序Web.py             # 起服务 + 自动开浏览器

# ② 原生界面（官方 ImGui 窗口 + Filament 3D）
.venv/bin/python 软件/主程序.py --检查
.venv/bin/python 软件/主程序.py
```

**两个入口的现状**：

| | `小软件.app`（自研窗口） | `小软件（原生界面）.app`（官方 ImGui） |
|---|---|---|
| 界面 | React（Web 技术栈） | 官方 ImGui 面板 |
| **3D 视口** | ✅ **MuJoCo 原生渲染**，实测约 58 fps，与界面左右分屏 | ✅ Filament |
| 真物理 / 算法 / 参数 / 辨识 / 录制 | ✅ | ✅ |
| 5 套风格 / 中英双语 | ✅ | ✅ |
| 官方 19 个 ImGui 面板 | ❌（能力由自研界面覆盖） | ✅ |

> 3D 是**真 MuJoCo 渲染**，不是网页里画的：由宿主窗口把原生视口放在界面右侧，
> 与 React 界面同级。前端**不按 URDF 自己算正运动学**——那会与物理漂移。

默认使用中文界面；更多启动参数、界面说明和算法扩展方式见[使用手册](报告/05_工程规范与治理/使用手册.md)与[软件说明](软件/README.md)。

## 项目结构

工作区顶层只保留分类文件夹（外加仓库标准门面文件与启动入口），没有散落的单个文件或脚本。

| 目录 | 内容 |
| --- | --- |
| `软件/` | 仿真工作台、界面、插件和项目装配逻辑；`软件/设备/` 是协议无关的设备抽象与安全层 |
| `算法库/` | 可插拔的控制、录制和参数辨识算法 |
| `模型/` | 可直接加载的 MuJoCo 模型与网格资产 |
| `项目/` | 模型与算法的项目配置（`项目/*.json` 是"哪个模型用哪些算法"的唯一数据源） |
| `工具/` | 环境重建、模型导入、打包、字体补丁、URDF 转 MJCF；`工具/验证/` 是可复跑的验证脚本 |
| `输出/` | 运行期状态与产物（设置、外观、面板布局、`04_记录/` 录制数据） |
| `报告/` | 全部报告与文档，按主题分类（见下） |
| `归档/` | 不再参与运行的历史产物（旧版应用包、离线安装 wheel） |

### 报告分类（`报告/`）

| 目录 | 内容 |
| --- | --- |
| `01_软件自检与状态/` | 自检报告、成熟度评估、优化工作索引 |
| `02_决策与架构方案/` | 独立化路线、换外壳工程量与架构决策 |
| `03_对标与调研/` | 与同类仿真软件、Ultralytics 的对标；上游调研素材 |
| `04_界面与外观优化/` | 侧栏改造、面板外观、风格样张 |
| `05_工程规范与治理/` | 完整工作报告、使用手册、工程化管理参考 |
| `06_验证与验收/` | 各验证脚本的输出日志与实测数据 |
| `07_历史快照/` | 历史版本说明与早期交付物（PPT 等） |
| `08_演示与汇报/` | 演示流程与台上手卡（导师/组会现场演示） |

顶层保留的仓库标准文件：`README.md`（本文件）、`LICENSE`、`CONTRIBUTING.md`、`CHANGELOG.md`、`requirements.lock`、`.gitignore`、`.github/`，以及启动入口 `小软件.app`。
